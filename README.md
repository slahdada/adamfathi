# 🌐 Adam Fathi — Portfolio Personnel

Un portfolio web professionnel développé en **HTML / CSS / JavaScript**, hébergé sur GitHub Pages.

## À propos

**adamfathi** est le site portfolio de **Adam Fathi**, présentant ses compétences, ses projets et ses informations de contact. Conçu avec une interface moderne et responsive.

## 🌐 Voir le portfolio en ligne

👉 [Ouvrir le portfolio](https://slahdada.github.io/adamfathi/)

## ✨ Sections du portfolio

- 👤 **Présentation** — à propos d'Adam Fathi
- 🛠️ **Compétences** — technologies maîtrisées
- 📁 **Projets** — réalisations et travaux
- 📬 **Contact** — informations de contact
